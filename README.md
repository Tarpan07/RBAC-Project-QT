 
# 📚 RBAC Library Management System (Qt + C++)

A **Role-Based Access Control (RBAC) Library Management System** built using **C++ (OOP)** with a **Qt Widgets UI**.
This project demonstrates modular design, authentication, and dynamic role management in a desktop application.

---

## 🚀 Features

* 🔐 User Authentication System (Login/Register)
* 🧑‍💼 Role-Based Access Control (RBAC)
* 📖 Library Management (Add / Remove / View Books)
* 🧾 Role Permissions (Admin, Librarian, User)
* 💾 Persistent Storage (Snapshots / File-based)
* ⚡ Write-Ahead Logging (WAL) for recovery
* 🎯 Clean Modular Architecture (Models, Services, UI)

---

## 🏗️ Tech Stack

* **Language:** C++
* **UI Framework:** Qt (Qt Widgets)
* **Concepts Used:**

  * Object-Oriented Programming (OOP)
  * File Handling
  * Authentication & Authorization
  * Modular Design
